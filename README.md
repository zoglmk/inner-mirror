# Inner Mirror — 内心镜

> 通过持续对话，慢慢看见真实的自己。

一个 Claude Code Skill，为那些想要倾诉、想要了解自己、想要记录成长过程的人而做。

---

## 它能做什么

- **安全的倾诉空间** — 不评判，不说教，像一个靠谱的老朋友在听你说话
- **完整存档对话** — 每次聊完自动保存完整的问答记录到本地，一句不少
- **积累自我画像** — 随着对话增多，逐渐形成对你这个人的深度理解
- **跨对话记忆** — 下次来聊，它记得你是谁、上次说到哪里

有些话，平时说不出口。说出来，被听见，被记录，就够了。

---

## 安装方法

**方式一：让 AI 帮你装**

把 `SKILL.md` 的内容复制，然后对 Claude Code 或其他 AI 工具说：

> "帮我把这个 skill 安装好"

粘贴内容，它会自动处理。

**方式二：手动安装（Claude Code）**

```bash
mkdir -p ~/.claude/skills/inner-mirror
cp SKILL.md ~/.claude/skills/inner-mirror/
```

重启 Claude Code 后生效。

---

## 使用方法

在 Claude Code 中，直接开始说就行：

- "我想聊聊最近的状态"
- "我有些话想说"
- "我最近压力很大"
- "我想和你谈谈"

Skill 会自动触发，不需要特别的指令。

聊完之后说"存"或"保存"，对话记录就会保存到当前目录的 `journal/` 文件夹里。

---

## 文件结构

使用后会在你的工作目录生成：

```
your-project/
├── journal/
│   ├── README.md
│   ├── 2026-05-16.md   # 按日期存档的完整对话
│   └── ...
└── memory/
    └── user_personal_profile.md  # 你的自我画像（持续更新）
```

## 适合谁用

- 平时没有人说话，想找个地方倾诉
- 感觉自己不够了解自己
- 想记录自己的成长过程
- 对"通过对话认识自己"这件事感兴趣的人

---

## 关于隐私

所有数据都保存在你自己的本地文件里，不上传任何地方。`journal/` 和 `memory/` 文件夹只有你自己能看到。

---

## 灵感来源

这个 skill 诞生于一次从"查书架"聊到"聊自己"的对话。

人通过说话来认识自己。说出来的东西，比想的更真实。积累多了，就能看见自己的轮廓。这就是成长的痕迹。
